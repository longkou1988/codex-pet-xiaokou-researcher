# 小扣研究员 · Codex 原生桌宠

这是中间 B 方向的正式可用包：原创迷你科研人物，不使用动物形象，也不带白色背景。

## 识别特征

- 短而整齐的黑发与大号黑框眼镜
- 黑色短袖、橙色纽扣徽章
- 蓝色资料板与知识卡片
- 冷静、好奇、可靠，强调核验、连接和讲解

## 可直接使用的文件

`package/xiaokou-researcher/` 是完整桌宠目录：

- `pet.json`：桌宠身份信息
- `spritesheet.webp`：Codex v2 动画图集，8 列 × 11 行，每格 192 × 208

`xiaokou-researcher-codex-pet.zip` 是同一目录的压缩包。

## 动画状态

依次包括待机、向右奔跑、向左奔跑、挥手、跳跃、受阻、等待核验、连接知识、展示成果，以及两组方向观察。

## 其他文件

- `concepts/`：A、B、C 三个方向的过程稿
- `references/`：最终 B 方向母版
- `generated/`：科研动作母版
- `final/`：透明动作图、PNG/WebP 图集和 64 像素头像
- `qa/`：图集预览与自动校验结果
- `prompts/`：最终绘图提示词
